What if we treat markdown files as a **memory substrate** for both humans and agents?

Humans get a polished local UX. Agents get deterministic structure. The same [[Wikilinks]] syntax works for both.

This is the core thesis behind combining the [[Zettelkasten Method]] with [[Local-First Software]].

The key insight: **the file system is the source of truth**, and everything else is derived.
