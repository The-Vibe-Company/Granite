## Summary

The **Zettelkasten** method is a personal knowledge management system developed by Niklas Luhmann. It emphasizes small, atomic notes connected through links.

## Key Principles

- Each note should contain **one idea**
- Notes should be linked to other notes via [[Wikilinks]]
- Use *permanent notes* for refined ideas
- Use *fleeting notes* for quick captures

## Details

The system works because of [[Backlinks]] — when you link to a note, you create a bidirectional connection. This allows emergent structure without rigid hierarchies.
